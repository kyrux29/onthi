    Hãy tạo bộ câu hỏi trắc nghiệm và chỉ trả về JSON hợp lệ, không markdown, không giải thích ngoài JSON.

Schema bắt buộc:
{
  "subject": "Tên môn học",
  "title": "Tên bộ câu hỏi",
  "questions": [
    {
      "chapter": "Tên chương",
      "topic": "Tên chủ đề",
      "difficulty": "Dễ | Trung bình | Khó",
      "questionType": "single | multiple | fill",
      "prompt": "Nội dung câu hỏi",
      "options": {
        "A": "Lựa chọn A",
        "B": "Lựa chọn B",
        "C": "Lựa chọn C",
        "D": "Lựa chọn D",
        "E": "Lựa chọn E nếu có",
        "F": "Lựa chọn F nếu có",
        "G": "Lựa chọn G nếu có",
        "H": "Lựa chọn H nếu có"
      },
      "answer": "A hoặc [\"A\", \"C\"] hoặc [\"đáp án text\"]",
      "explanation": "Giải thích rõ vì sao đáp án đúng và vì sao các lựa chọn khác sai.",
      "example": "Ví dụ cụ thể trong môn học.",
      "tips": ["Mẹo 1", "Mẹo 2"],
      "optionAnalysis": {
        "A": "Phân tích lựa chọn A",
        "B": "Phân tích lựa chọn B",
        "C": "Phân tích lựa chọn C",
        "D": "Phân tích lựa chọn D"
      }
    }
  ]
}

Yêu cầu nội dung:
- Tạo [SỐ_LƯỢNG] câu.
- Môn: [TÊN_MÔN].
- Chương/chủ đề: [CHƯƠNG_HOẶC_CHỦ_ĐỀ].
- Phối hợp 3 loại câu khi phù hợp: single, multiple, fill.
- Với single: answer là "A"; với multiple: answer là ["A","C"]; với fill: options là {} và answer là ["đáp án 1","đáp án tương đương"].
- Câu fill vẫn phải có explanation/example/tips đầy đủ; explanation cần nêu vì sao đáp án ngắn đó đúng và các cách viết tương đương.
- Câu trắc nghiệm có thể có 4-8 lựa chọn, dùng các khóa A-H.
- Giải thích phải đủ rõ để người học hiểu ngay sau khi chọn đáp án.
- Sắp xếp câu hỏi theo chapter rồi topic.
